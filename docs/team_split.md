\# Team Split



\## Project Team



The project is divided into four major work areas. Each member is responsible for a specific stage of the overall pipeline, while integration is handled collaboratively.



\---



\## Person 1: Data \& Feature Engineering



\### Responsibilities



\* Explore and understand the publicly available startup dataset.

\* Examine the available CSV files and identify relevant attributes.

\* Perform data cleaning and preprocessing.

\* Select the relevant data required for the modelling dataset.

\* Create the structured \*\*100-project modelling dataset\*\*.

\* Perform feature selection and feature engineering.

\* Generate the \*\*Investment Potential Score\*\*.

\* Create the scored dataset used by the optimization models.

\* Maintain the data preparation and feature engineering notebooks/scripts.

\* Document the dataset, selected features, transformations, and scoring methodology.



\### Main Outputs



\* Processed dataset

\* 100-project modelling dataset

\* Scored startup dataset

\* Data dictionary

\* Data preparation documentation



\---



\## Person 2: Integer Programming



\### Responsibilities



\* Formulate the startup portfolio selection problem as a \*\*Binary Integer Programming\*\* problem.

\* Define the decision variables.

\* Define the objective function.

\* Define the budget constraint.

\* Implement the Integer Programming model using \*\*PuLP\*\*.

\* Run the model under different budget scenarios.

\* Generate the selected startup portfolios.

\* Calculate total investment and total Investment Potential Score.

\* Validate the optimization results.

\* Document the mathematical formulation and implementation.



\### Main Outputs



\* Integer Programming model

\* Budget-based optimization results

\* Selected project portfolios

\* Optimization result files

\* Integer Programming documentation



\---



\## Person 3: Goal Programming



\### Responsibilities



\* Study and formulate the \*\*Goal Programming\*\* approach.

\* Define the multiple objectives of the investment problem.

\* Identify appropriate goals and target values.

\* Define deviation variables and goal priorities/weights.

\* Formulate the Goal Programming model.

\* Implement the model using the prepared dataset.

\* Generate optimized portfolios using multiple goals.

\* Compare Goal Programming results with Integer Programming results.

\* Document the formulation, implementation, and results.



\### Main Outputs



\* Goal Programming formulation

\* Goal Programming implementation

\* Multi-objective optimization results

\* IP vs GP comparison

\* Goal Programming documentation



\---



\## Person 4: Analysis, Integration \& UI



\### Responsibilities



\* Perform overall analysis of the generated results.

\* Analyze investment patterns and optimization outcomes.

\* Perform scenario and sensitivity analysis.

\* Compare different budget scenarios.

\* Compare Integer Programming and Goal Programming results.

\* Integrate the outputs from all team members.

\* Design and implement the project user interface.

\* Allow users to load/view the dataset.

\* Provide statistical information through the interface.

\* Allow users to select an optimization technique.

\* Display optimization results and portfolio selections.

\* Coordinate the final integration of the complete system.

\* Prepare final project presentation and demonstration.



\### Main Outputs



\* Statistical and scenario analysis

\* IP vs GP comparison

\* Integrated project

\* User interface

\* Final visualizations

\* Final presentation and demonstration
